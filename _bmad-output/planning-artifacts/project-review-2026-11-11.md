# 叶子弦谱项目走查与改进计划

2026-11-11 · 基线 4006dfe

## 需求与验收

根据现有谱面编辑计划、操作体验和验证报告，从录谱、改谱、试听、保存、导出五个环节走查。总谱、分谱和导出使用同一份工程数据。新增编辑操作应能整次撤销，失败时应保留原谱。

| 用户任务 | 通过条件 |
| --- | --- |
| 批改一段旋律 | 可以拖选、Shift 连选和 Ctrl 跳选音符。时值按拍位改一次，音高只改选中的音；休止可改时值。跨小节批量改完后可以一次撤销。 |
| 复制一段旋律 | 同一分谱、同一声部的音符按谱面顺序复制。从目标拍位起连续覆盖，允许跨小节。完整选中的范围记号生成新端点；跨出选区的连线保留在原谱。 |
| 校对简谱 | 单音与叠音最下方的数字对齐。同一谱行内相邻的同类减时线对齐。编辑页与导出预览一致。附加声部有自己的简谱行。 |
| 保存大工程 | 读写使用同一字节上限。接近上限时用紧凑格式保存；超过上限时保留原文件和编辑状态。 |

## 走查发现与处理

| 范围 | 复现结果与本轮处理 |
| --- | --- |
| 音符和小节选择 | 音符拖动与小节拖动曾走同一入口，面板只接收单拍。现在从音符开始拖动选音符，从小节号或小节条操作小节。批量延长按各拍的时值计算，保留相邻音符。新增拍数超限的提示。 |
| 剪贴板和撤销 | 小节剪贴板无法复用旋律片段。音符粘贴支持拍位覆盖、跨小节和一次撤销。校验目标容量和吉他定弦后再写入，保留未覆盖的声部。 |
| 叠音和复调 | 叠音的中心对齐与最新的底部对齐要求冲突；简谱渲染也曾漏掉附加声部。叠音现在向上排，简谱附加声部单列，可点选并导出。 |
| 文件与恢复 | 读取有 16 MB 上限，保存曾可能写出超过上限的工程。桌面读写和浏览器入口统一校验，保存接近上限时改用紧凑格式，并阻止重复保存互相覆盖。 |
| 试听与走谱 | 现有自动化覆盖反复、房子、D.S. al Coda、跨页跟随和独立分谱试听。批量修改后的音高和时值沿用现有工程模型与播放逻辑。 |
| 导入与交付 | 已有 MIDI 导入、PDF／PNG 导出和独立分谱设置。MIDI 导入仍有量化和技法转换边界；复杂乐谱需要更多真实样谱核对。 |

## 验证结果

- 39 项工程数据测试通过。包括同拍多音的批量时值、休止、个别叠音移调、超界时整次保留原谱、跨小节粘贴和范围记号端点。
- 40 项界面工作流测试通过。包括音符拖选、批量时值与音高、跳选复制及撤销、叠音减时线对齐和附加声部导出。
- Windows 新版通过原生试听、保存重开、PDF 与 PNG 导出、分谱批量导出及重名保护检查。另用原生读写命令核对超限项目会被拒绝，原文件内容保留。

## 后续故事

| 优先级 | 交付 | 验收 |
| --- | --- | --- |
| P1 | 给音符粘贴增加插入和选区逐一覆盖；整理音符与小节菜单的入口。 | 在跨小节、变拍和已存在连线的乐句中完成插入、覆盖、撤销。确认其他声部时间轴符合用户所选的操作。 |
| P1 | 给曲谱增加交付前检查。汇总超拍、走谱错误、移调后不可演奏的吉他音，并定位到相应小节。 | 从检查结果定位总谱和分谱，逐项修正后重新试听及导出。 |
| P1 | 优化密集多声部简谱的间距。为同一分谱内的各声部单独处理歌词、低音点、技法和渐强渐弱的避让。 | 用有三个声部的简谱核对编辑页、PDF 和 PNG 的同小节对齐与可读性。 |
| P2 | 设计 MusicXML 导入导出，先覆盖五线谱、歌词、附加声部、曲式和调拍变化。 | 用至少两个支持 MusicXML 的编辑器往返比对；在导出前报告简谱与自定义技法的转换差异。 |
| P2 | 增加 MIDI 导入量化选项和乐器映射预览。 | 用弱起、多声部、三连音、踏板和跨小节长音样例逐项比较导入结果。 |
| P2 | 继续校对竹笛、古筝和西洋乐器的符号，明确每种技法的谱面和试听效果。 | 每个乐器至少用一份实际谱例做编辑、保存、导出和试听检查。 |
