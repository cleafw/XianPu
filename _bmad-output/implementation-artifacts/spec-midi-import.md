## 目标与范围

从本机选择 `.mid` 或 `.midi` 后生成新的可编辑弦谱工程。用户能打开总谱和各乐器分谱、编辑、试听、另存为 `.xianpu`。导入过程全程本地，旧工程沿用现有保存确认，文件读取或解析失败时保留原工程。

支持按四分音符分辨率计时的标准 MIDI 0／1 型。按源音轨、通道和音色区分乐器，保留有效音高、休止、和弦及重叠音符，跨小节的持续音用延音线。保留可表达的拍号、调号和速度，小节中的变化按小节边界处理并提示。首版统一量化到三十二分音符，尽量保留短音并告知用户；特殊连音、力度、踏板、弯音、歌词与演奏法交由后续编辑。小调沿用调号的升降号，工程当前以大调名称显示。

旋律默认五线谱，可切换简谱。识别 GM 打击乐及吉他。只有能从标准定弦分配互不冲突的弦品时生成六线谱，否则保留音高并使用五线谱。无法精确匹配试听音色时使用库内相近预设并提示。

| 输入 | 结果 |
| --- | --- |
| 单轨多通道 MIDI，含零力度关音或运行状态 | 正确配对音符并生成多个乐器分谱 |
| 多轨 MIDI，含拍号／调号／速度、同起止和弦、重叠或跨小节音符 | 生成对齐小节，保留和弦、声部和延音 |
| 无音符、截断、格式不支持或超出工程上限 | 给出可读提示，保留正在编辑的谱子 |

## 代码映射

- `src/model.ts` 的 `createTrack`、`layout`、`ticks` 和 `parseProject` 提供现有数据结构和边界。乐谱上限 256 小节、24 乐器、每轨 4 声部、每拍 16 音；单乐器超出声部上限可拆成额外乐器，整曲超出则拒绝。支持的拍号分母是 2、4、8、16，分子 1–12。
- `src/score.ts` 与 `src/playback.ts` 已用 `Beat.tie` 表示延音到达。把同起止音归组并分配声部，避免给重新触键的同音误加延音。
- `src/main.tsx` 用 `load`、`whenClean`、`fromBrowser` 和工具栏。浏览器继续使用现有唯一文件输入，避免影响已有入口及测试。桌面用现有 Tauri 对话框和新的二进制读取命令。
- `src/sounds.ts` 提供现有音色名和可用程序号，`src/i18n.ts` 提供双语提示。现有 alphaTab 没有向前端公开 SMF 读取器，新增受限的 SMF 解码器。使用有界读取、无符号块长和最长四字节的变量长数，超出边界立即失败。

## 实现记录

- Windows 原生文件选择框实测从 MIDI 生成钢琴、吉他和鼓组分谱，共 2 小节、11 个音符。另有五份公开样本通过工程回读校验。
- 补充分谱操作。新建与示例默认按简谱、吉他六线谱、五线谱命名，已保存的分谱名保留。侧栏可删除分谱，支持取消、撤销和最后一份分谱保护。
- 33 项单元测试和 22 项界面测试通过，覆盖导入、编辑、试听、保存重开、失败保护和分谱管理。

## 复核记录

- 文件读取按请求顺序提交结果，保存确认取消后不会触发替换。导入详情随当前工程保留。
- 核对共享通道音色、结束音符指令、变拍边界、非正拍音值、自动指法、解码上限和输出体积。延音通过谱面模型和试听事件验证。
