## 需求与验收

- Windows 工具面板用独立窗口承载，能跨出主窗口、移到另一块屏幕。弹出和贴回时保留控件状态及当前工程，不复制工程。
- 底部录入位置采用同一弹出交互。独立窗能定位小节、使用选区及复制粘贴，主谱面同步。
- 时值、音高和其他编辑面板按录入、导航、移除分组。清空拍位、删除小节和删除记号放在独立的操作区域。
- 验收覆盖原生窗口生命周期、浏览器回退、键盘操作、选区联动以及按钮分组。

## 实现与验证

- Windows 工具窗与主窗口共用正在编辑的谱子。拖系统标题栏移动，关闭工具窗或点 ↙ 可贴回原位。浏览器版继续使用页面内浮窗。
- 音高把休止、拍位导航和清空分组，录入位置、记号和成组连音也分隔移除按钮。
- Windows 预览实测音高窗越过主窗口左边界，关闭后恢复右栏。录入位置能在独立窗口打开。跨显示器移动未单独实测。
- 22 项单元测试与 18 项界面测试通过。新增独立文档测试覆盖连续拖选、谱面联动、快捷复制粘贴、右键菜单与贴回。

## 复核修正

- 将所选小节提示放到小节按钮下方，避免鼠标按下后按钮移位并打断拖选。
