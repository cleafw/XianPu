# 叶子弦谱 · Leaf Notation

用于中文弹唱、吉他指弹和小型乐队的 Windows 离线写谱工作台。

## 开始写谱

1. 双击桌面快捷方式「Leaf Notation」。要使用当前源码中的功能，可按下方说明构建并打开 Windows 桌面版。
2. 点「打开弹唱示例」查看八小节混排，也可打开 [沿着晚风工程](examples/沿着晚风.xianpu)。要从头写歌，选择「简谱弹唱」「吉他指弹」或「多乐器总谱」。
3. 直接点总谱上目标声部的拍位，录入面板会切换到该声部。「录入位置」也可用于键盘操作。简谱用数字输入，吉他先选弦再加入品位，五线谱可点录入面板里的谱线。右侧可设置时值、歌词、和弦和演奏记号。
4. 左栏可在总谱与分谱之间切换。点「添加分谱」可选简谱、吉他六线谱或五线谱。点分谱旁的 × 可从工程中删除，误删后可撤销。分谱可单独设置每行小节数和每页谱行数。
5. 保存为 `.xianpu`。点「导出」，选择 PDF 或 PNG 图片，再选当前谱、总谱或多份分谱。PNG 每页一张，多页时选择一个文件夹。批量输出遇到同名文件会停止，并提示已保存的数量。
6. 左栏「试听音色」可为每个声部分配不同音色，也可一键统一。内置 66 个 NeuralNote 试听音色，包括合唱人声。合唱音色用元音演奏旋律。
7. 左栏底部「纸张设置」可选 A4、A3 或填写自定义宽高。分谱默认跟随总谱，也可单独设置。纸张尺寸用于排版、预览与 PDF。

**谱面编辑。** 从谱面音符拖动或用 Shift 连选音符，按住 Ctrl 可增减单个音符。用时值和音高面板批量修改，Shift+↑／↓ 升降八度。Ctrl+C 复制同一声部的音符，点目标拍位后 Ctrl+V 连续覆盖。小节选择可从小节号或下方小节条开始，右键提供小节覆盖、前插和后插。

**导入 MIDI。** 在主工具栏点「导入 MIDI」，选择本机的 `.mid` 或 `.midi` 文件。确认当前工程的保存选项后，导入结果会作为新的可编辑总谱打开。可在左栏切换乐器分谱，编辑、试听，再保存为 `.xianpu`。读取或转换失败时会保留当前工程。

导入支持按四分音符计时的标准 MIDI 0／1 型，按源轨、通道和音色分谱。发声音轨自身的音色设置只作用于该轨，专门的控制轨可为同通道分配音色。音符和休止对齐到三十二分音符，短音至少保留一格。同起止的音符组成和弦，重叠的音符使用不同声部，跨小节的持续音用延音线。可表示的拍号、调号和速度保留，曲中变化放在下一个小节边界，小调以对应的大调名称显示。默认使用五线谱，可切换简谱。GM 鼓组使用打击乐谱，能分配到标准定弦且在 0–24 品范围内的吉他使用六线谱。导入详情会提示量化、音色替换等转换结果。

首版将特殊连音、力度、踏板、弯音、歌词和演奏法留给后续编辑。工程上限为 256 小节、24 个乐器、每乐器 4 个声部和每拍 16 个音符。超出四声部的乐器可拆成多个分谱，MIDI 文件和转换后的工程均限 16 MB。

**技巧与曲式。** 右侧「记号面板」可按乐器或名称查找技法，添加单点记号、跨音记号及自定义文字。选中小节后，「曲谱设置」提供反复房子、D.C.／D.S.、排练号、曲中换拍和打印分页。技法面板区分仅谱面和带试听的记号。

**试听和工作区。** 试听时蓝色光标按实际播放顺序逐拍移动，越出视野时谱面自动滚动。右侧各组可折叠，标题右侧 ↗ 可弹出成可拖动面板，↙ 贴回右栏。

右上角可选「跟随系统」「简体中文」或「English」。跟随系统时，Windows 中文界面使用简体中文，其他语言使用英文。手动选择会记住。项目中的曲名、歌词和乐器名按原文保留。

## 构建和检查

- 运行 `npm ci` 安装依赖。
- 运行 `npm run desktop -- dev` 启动桌面开发版，或运行 `npm run dev` 检查界面。
- 运行 `npm test` 检查工程数据，运行 `npx playwright test` 使用本机 Edge 检查编辑流程。
- 运行 `npx tauri build --no-bundle --target x86_64-pc-windows-msvc` 生成 Windows 验收程序。默认输出为 `src-tauri/target/x86_64-pc-windows-msvc/release/yezi-xianpu.exe`。
- 运行 `npx tauri build --target x86_64-pc-windows-msvc` 构建带 WebView2 离线安装程序的 NSIS 安装包。默认输出在 `src-tauri/target/x86_64-pc-windows-msvc/release/bundle/nsis`。
