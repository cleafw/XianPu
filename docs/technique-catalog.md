# 演奏技巧记号的覆盖与来源

右侧「记号面板」支持按乐器、中文、英文和常见别名查找。网格与列表显示将写入谱面的记号，下拉模式保留独立的「添加记号」操作。可在单拍添加记号，也可为跨音记号指定起止拍。

| 乐器或记号类 | 本次核对的内容 | 依据 |
| --- | --- | --- |
| 竹笛 | 上历音、下历音分别用上斜、下斜的短折线；检索「立音」可找到这两个选项。另补腹震音、虚指颤音、循环换气、音前滑音和余音。 | [六孔竹笛演奏符号研究及谱例](https://www.huain.com/article/dizi/2026/0121/3536.html) |
| 古筝 | 历音、琶音、泛音、揉弦、点奏、连托、连抹、连勾、轮抹、轮勾、轮撮、双托和双按音。 | [国家高等教育智慧教育平台古筝课程](https://higher.smartedu.cn/course/671984e116d8a05eedc3eb0e) · [中南大学出版社古筝教程](https://csup.csu.edu.cn/info/1031/7752.htm) |
| 琵琶与扬琴 | 弹、挑、轮、滚、扫拂、泛音、吟、双音和轮竹等；琵琶长轮可标起止。 | [教育部审定高中音乐演奏教材](https://r3-ndr.ykt.cbern.com.cn/edu_product/esp/assets_document/2e1c67c1-baa6-4720-854a-a0df486090bc.pkg/pdf.pdf) |
| 二胡、唢呐、笙 | 内外弦、揉弦、抖弓、弹舌、唇颤、指颤、历音和传统和声等。 | [GB/T 16431-2008，第 7 章演奏符号](https://www.chemalink.net/standard/download/34caf5e512d27dfc.html) |
| 通用、人声、吉他、弓弦、管乐、键盘、打击乐 | 补齐常用装饰音、方向琶音、发音方式、弓法、弱音器、拨片、踏板、击奏与响弦等选项。 | [简谱通用规范 GB/T 46845-2025](https://std.samr.gov.cn/gb/search/gbDetailed?id=4507EFE13D10CB6AE06397BE0A0A601F) · [MusicXML 记谱元素](https://www.w3.org/2021/06/musicxml40/listings/musicxml.xsd/) · [SMuFL 字形目录](https://github.com/w3c/smufl/blob/gh-pages/metadata/glyphnames.json) |

用于指定实际音高的小音符可以从「倚音与成组连音」或在记号面板搜索「小音符」录入。每拍可依次添加最多四个前倚音，试听会按所录音高发声。琶音和大部分新增演奏法作为谱面记号标注，面板会说明记号是否参与试听。

已核对的图形使用矢量路径或 SMuFL 字形。有地区、教材或流派差异，且尚未逐字形核对的项目使用中文名称、传统文字标注或演奏术语。遇到不同谱本写法时，可以使用「自定义文字或符号」。
