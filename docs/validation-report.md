# 弦谱界面与交付验收

2026-11-10 · v0.1.0

采用 BMAD 6.12.4 的 UX 设计契约和验证清单。依据 [视觉设计](../DESIGN.md) 与 [操作体验](../EXPERIENCE.md)，从首次写谱、熟练录入、错误恢复和可访问性四个视角走查。原型与实机结果均由实现者复核。

| 检查项 | 发现与修正 | 复测结果 |
| --- | --- | --- |
| 首次进入 | 首页以三个模板说明用途，添加可直接打开的八小节弹唱示例 | 模板进入后可立即录简谱并选吉他分谱 |
| 录入位置与键盘 | 早期谱面缺乏可见光标，增加拍位高亮、小节文字和语义状态 | 点击谱面能从第 1 拍移到第 2 拍，按钮和键盘均可录入 |
| 分谱和布局 | 总谱与分谱分别保存版式，共享音符 | 分谱改音能在总谱看到，独立换行设置保持分离 |
| 中文排版与缩放 | 为歌词增加垂直间距，窄窗口的七个简谱键固定一行 | 检查 840 像素宽界面和中文谱面预览 |
| PDF 分页与字体 | 初版把指法图区算成谱行，且预览复制后丢失音乐字体样式。改用实际谱行计数，保留音乐字体作用范围 | Windows 原生导出总谱、分页总谱和三份分谱，均为 A4 |
| 文件恢复与错误 | 草稿优先处理，损坏文件保留当前工程，批量重名和占用文件有提示 | 恢复与损坏工程用例通过，实机覆盖重名和占用，原文件内容保留 |

## 验证方式

- 四项数据测试和三项浏览器工作流测试通过。覆盖从空白录八小节、简谱与歌词、同拍多弦、五线谱、保存重开、分谱、撤销和草稿恢复。
- Windows 发布程序通过本地烟测，使用真实保存命令和 WebView2 PDF 导出。测试自动提供文件对话框的选中路径。
- 安装包已构建。当前 Windows 环境验证了发布程序，干净系统上的安装过程和外部首次使用者访谈待后续验收。

## v0.2.0 叶子弦谱

- 四项工程数据测试和六项界面测试通过。新增实点总谱的吉他和五线谱空拍、录入校验、并排吉他谱表选择，以及日语环境回退英文、切换与重开保留设置。
- Windows 发布程序烟测通过。验证系统语言、手动中英切换、原生保存重开和分谱 PDF。
- 桌面「叶子弦谱」快捷方式已打开新版窗口。

## v0.3.0 试听音色与纸张

- 界面测试覆盖逐声部更换音色、一键统一为合唱人声、草稿恢复和独立分谱试听。测试检测合成器实际输出的音频采样，另验证仅使用鼓组的分谱出声。
- Windows 发布程序导出 A4 总谱、A3 总谱和 330 × 220 mm 吉他分谱。检查 PDF 页面尺寸、中文歌词、谱线与分页。分谱默认跟随总谱，单独设置后保留总谱的尺寸。

## 导出图片

- Windows 发布程序验证了 330 × 220 mm 吉他分谱的单张 PNG、A3 总谱的两张编号 PNG，以及按各自纸张尺寸批量导出三份分谱。批量重名时原文件保留。
- 检查了 PNG 文件的像素尺寸、中文歌词和音乐字形。原生 PDF 导出回归测试通过。

## 谱面编辑与试听跟随

- 22 项工程、剪贴板及曲式数据测试通过。覆盖跨小节记号复制、附加声部对齐、第一／第二房和 D.S. al Coda。
- 17 项 Edge 工作流测试通过。包含谱面拖选、覆盖／撤销、插入、升八度、技法与倚音、实际 PNG 中的记号、分谱独立分页和总谱／分谱的 MIDI 走谱。
- 使用有反复的 12 小节乐谱试听，检查光标逐拍前进、回跳和超出视野自动滚动。停止后保留原编辑位置。
- 验证录入区逐组折叠、同时弹出两个面板、拖动、添加记号及贴回后的搜索状态。
- Windows 本地可执行版启动和示例打开已检查。此次完整原生文件对话框与 PDF 批量导出回归未运行。
